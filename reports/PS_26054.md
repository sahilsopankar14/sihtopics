# SIH 2026 Problem Statement Report

## 1. Problem Statement Overview

- **Problem ID:** 26054
- **Problem Title:** Digital Twin Framework for Aero Piston Engines in MALE UAVs
- **Organization:** Defence (Implied)
- **Category:** Software
- **Theme:** Aviation / Defence / Digital Twin
- **Difficulty Level:** Very Hard

### Problem Statement

> Medium Altitude Long Endurance (MALE) UAVs are deployed for ISR missions. Reliability of piston-engines is critical. Conventional engine monitoring systems are threshold-based and reactive. A Digital Twin framework for aero piston engines can improve predictive maintenance by creating a virtual representation using real-time sensor data, physics-based models, and AI/ML. The problem aims to develop an indigenous DT framework for real-time state estimation, anomaly detection, degradation tracking, and mission replay.

### One-Line Summary

A software system that uses AI and physics simulations to monitor the health and predict failures of UAV aircraft engines in real-time.

---

## 2. Problem Understanding

### What is the actual problem?

Military drones (UAVs) use combustion engines. If an engine fails mid-flight, the drone crashes. Currently, operators only get alerts when something is already wrong (e.g., temperature too high). They want a "Digital Twin"—a virtual, mathematical copy of the engine that runs parallel to the real one, predicting failures *before* they happen.

### Who faces this problem?

Defence forces, UAV operators, aerospace engineers.

### Why is this problem important?

Prevents the loss of multi-million dollar military assets and ensures mission success for national security.

### Existing Problems / Limitations

Current systems only trigger alarms when fixed thresholds are crossed. They cannot predict how much longer the engine will survive (Remaining Useful Life) or simulate how weather/altitude affects engine wear.

---

## 3. Expected Solution

### What is SIH asking us to build?

A highly advanced software platform comprising:
1. Real-time data ingestion from engine sensors (CAN bus).
2. Thermodynamic physics models of the engine.
3. AI/ML models for anomaly detection and predicting Remaining Useful Life (RUL).
4. A simulation module to replay missions and test weather effects.
5. A detailed visualization dashboard.

### Proposed Solution Concept

A cloud/edge hybrid dashboard. We simulate an engine sending telemetry via CAN protocols. Our backend receives this, runs it through an ML anomaly detector (trained on simulated engine data), and compares it against basic physics formulas to predict failures like misfires or overheating.

### Key Features

- Ingestion of simulated RPM, Temperature, Pressure, Vibration data.
- AI/ML based Remaining Useful Life (RUL) calculation.
- Detection of sensor drift and combustion instability.
- Visualization dashboard with 3D engine model (optional) and graphs.

## 6. Data Requirements

### Required Data

Time-series sensor data of aero piston engines (RPM, CHT, EGT, fuel flow, vibration) under normal and failing conditions.

### Data Availability

**Level:** Low

### Possible Data Sources

- NASA Turbofan Engine Degradation Simulation Data Set (CMAPSS) - Note: this is for jet engines, not piston engines, but mathematically similar for ML purposes.
- Writing a python script to synthetically generate realistic piston engine data.

### Data Challenges

Real defence UAV engine data is classified or strictly proprietary. We will be forced to use synthetic data or unrelated public datasets, which makes proving the "physics-based model" extremely difficult.
