# SIH 2026 Problem Statement Report

## 1. Problem Statement Overview

- **Problem ID:** 26140
- **Problem Title:** AI-powered Interactive Platform for Quantum Computing Education
- **Organization:** AICTE / Ministry of Education (Implied)
- **Category:** Software
- **Theme:** Education / Quantum Computing
- **Difficulty Level:** Hard

### Problem Statement

> Quantum computing is transformative but hard to learn due to abstract concepts. Existing resources are static and theoretical. There is a need for an interactive, AI-powered web platform where students can learn, design, simulate, and visualize quantum circuits using a drag-and-drop interface, supported by AI tutoring.

### One-Line Summary

A web application with a drag-and-drop interface and an AI tutor to help students learn and simulate quantum computing circuits.

---

## 2. Problem Understanding

### What is the actual problem?

Learning quantum computing currently requires reading dense math textbooks or writing complex Python code (like Qiskit). Students need a visual, interactive tool (like Scratch for Quantum) that explains concepts using AI and lets them build circuits visually.

### Who faces this problem?

University students, researchers, and educators in physics and computer science.

### Why is this problem important?

Quantum computing is the next frontier of technology, and India needs to rapidly train a workforce to understand it.

### Existing Problems / Limitations

IBM Quantum Experience exists but is highly technical. There is a lack of guided, AI-tutored, beginner-friendly visual platforms.

---

## 3. Expected Solution

### What is SIH asking us to build?

An educational website. It must have:
1. Theoretical learning modules.
2. A drag-and-drop visual circuit builder.
3. Integration with simulators (Qiskit, Cirq) to run the visual circuits.
4. An AI chatbot/tutor to explain errors and concepts.
5. Visualizations (like the Bloch sphere).

### Proposed Solution Concept

A React/Next.js frontend with a canvas for dragging and dropping quantum gates (Hadamard, CNOT, etc.). The frontend translates the visual blocks into a Python Qiskit script, sends it to a Python Flask backend, runs the simulation, and returns the probability charts. An OpenAI API wrapper acts as the AI tutor.

### Key Features

- Visual circuit builder.
- Multi-framework simulation backend.
- Bloch sphere 3D visualization (using Three.js).
- AI Chatbot for tutoring.
